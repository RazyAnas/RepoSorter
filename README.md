# 🛠 How to install (unpacked, for dev use)

- Unzip github-repo-sorter.zip
- Open Chrome → go to chrome://extensions
- Enable Developer mode (toggle, top-right)
- Click Load unpacked → select the github-repo-sorter/ folder
- Pin the extension to your toolbar


# ✨ Features

- Sort by: Name, Date Modified (last commit), File Size, File Type (extension), Commit Message
- Direction: Ascending / Descending toggle
- Inline sort bar injected directly above the file table on GitHub — no page reload needed
- Popup panel shows status (active/inactive), lets you pick sort options, and apply/reset
- Smart detection — only activates on repo file listing pages (/user/repo, /user/repo/tree/branch/...), not issues, PRs, etc.
- GitHub nav-aware — handles turbo/pjax navigation when you browse between repos without a full reload
